# Arduino Robot Challenge

## Project Overview

The Arduino Robot Challenge is a hands-on robotics project involving mechanical assembly, embedded programming, and sensor-based movement control.

The robot uses an Arduino Uno as its main controller. Two servo motors drive the wheels, while a pushbutton and photoresistor provide input for controlling its behavior. Three LEDs provide visual indicators.

## Components

- Arduino Uno
- 2 servo motors
- 2 wheels and robot chassis
- Breadboard
- Pushbutton
- Photoresistor (light sensor)
- 3 LEDs: red, green, and yellow
- Battery holder and power connections
- Jumper wires

## How It Works

The robot combines sensor input, programmed logic, and motor control to produce different movement responses.

- **Pushbutton:** Activates the robot.
- **Photoresistor:** Detects changes in surrounding light.
- **Servo motors:** Control wheel movement.
- **LEDs:** Provide visual feedback.

Based on the light conditions detected by the photoresistor, the robot can perform different movements:

- Move forward
- Move in reverse
- Spin

## System Workflow

1. The Arduino initializes the connected components.
2. The pushbutton activates the robot.
3. The photoresistor detects the surrounding light level.
4. The Arduino processes the sensor input using programmed conditions.
5. The servo motors execute the corresponding movement.
6. The LEDs provide visual feedback.
